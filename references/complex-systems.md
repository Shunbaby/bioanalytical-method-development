# 复杂体系下的生物分析选择

> 复杂体系的核心不是“换一台更贵的仪器”，而是先定义分析物、基质形态、游离/总浓度和归一化方式。

## 1. 选择树

```text
分析物是蛋白/抗体/ADC?
├─ 是 → 有可靠抗体对?
│   ├─ 有 → LBA（总抗体/偶联抗体/完整分子）
│   └─ 无 → hybrid LBA-LC-MS 或 LC-MS 特征肽
└─ 否（小分子/ payload/代谢物）→ LC-MS/MS

需要“游离”浓度?
├─ 是 → 先分离（平衡透析/超滤/SPE/免疫富集），再定量
└─ 否 → 总浓度；确认是否含 DAR0/结合蛋白/复合物

基质是组织/肿瘤/细胞?
├─ 是 → 匀浆 + 归一化（蛋白量/组织重量）+ 个体基质验证
└─ 否 → 血浆/血清；查抗凝剂、溶血、脂血

内源性生物标志物?
├─ 是 → surrogate matrix / 稳定同位素 / 基线扣除；fit-for-purpose
└─ 否 → 标准曲线 + QC
```

## 2. 基质选择与归一化

| 基质 | 主要难点 | 推荐策略 |
|---|---|---|
| 血浆/血清 | 抗凝剂、溶血、脂血、蛋白结合 | 固定抗凝剂；个体基质；溶血/脂血单独验证 |
| 全血 | 细胞摄取、酯酶、溶血 | 冰浴、快速处理、加抑制剂；DBS 需验证血细胞比容 |
| 组织（肝/肾/肿瘤/皮肤） | 异质性、匀浆效率、蛋白量差异 | 匀浆 + 蛋白/重量归一化；多点取样；个体基质 |
| 脑/CSF | 低浓度、血脑屏障、基质少 | 低吸附管；大体积浓缩； surrogate matrix |
| 尿/胆汁/粪 | 盐、胆红素、微生物、结合物 | 稀释/SPE；酶解结合物；基质校准 |
| 细胞/亚细胞 | 摄取、裂解效率、器室 | 分离 + 裂解验证；蛋白归一化；不要直接套血浆方法 |
| 玻璃体/房水 | 微量、低蛋白 | 低吸附、微量法、标准加入法 |

## 3. 游离 vs 总浓度

| 目标 | 方法 | 关键点 |
|---|---|---|
| 游离药物 | 平衡透析、超滤、超速离心 + LBA/LC-MS | 膜吸附、平衡时间、温度、pH、回收率 |
| 总药物 | 直接 LBA/LC-MS | 是否含结合蛋白/复合物/DAR0 |
| 游离 payload | 分离 + LC-MS/MS | ex vivo 释放、内酯/开环、源内碎裂 |
| 总 payload | 释放/酶解 + LC-MS/MS | 释放完全性；linker-payload 通道 |
| 组织总暴露 | 匀浆 + LC-MS/LBA | 归一化方式必须报告 |

**ADC 的“游离 payload”不是“总 payload 减去偶联 payload”**：需要实际分离和独立标准品；总 payload 方法不能回答游离浓度。

## 4. 内源性生物标志物

- 没有真正的空白基质：用 surrogate matrix（替代基质）、 stripped matrix、或标准加入法。
- 用稳定同位素标记内标；若内标不存在，用结构类似物并验证。
- 基线扣除：疾病/给药前水平；报告绝对值和变化值。
- 接受标准按 fit-for-purpose，不要硬套 M10 的 PK 标准。
- 复杂基质（组织/CSF）优先 LC-MS/MS；LBA 需证明抗体不再识别相关内源物。

## 5. ADC / 抗体类复杂体系

| 体系 | 分析物 | 方法 | 注意 |
|---|---|---|---|
| 总抗体 | 所有 IgG，含 DAR0 | LBA 抗 IgG/抗 CDR | 不能代表 ADC |
| 偶联抗体 | DAR≥1 | LBA anti-payload 捕获 + anti-Fc/anti-ID 检测 | 通常不随 DAR 线性变化；不能直接相减得 DAR0 |
| 偶联 payload | 共价 payload 质量 | LBA anti-Fc/anti-ID 捕获 + anti-payload 检测；或 LC-MS | DAR 敏感；需 DAR 匹配标准品 |
| 总 payload | 偶联+游离 | 释放 + LC-MS/MS | 释放完全性 |
| 游离 payload | 未偶联/释放 | 分离 + LC-MS/MS | ex vivo 释放 |
| DAR/DLD | 载荷分布 | HIC/native MS/LC-MS | 高疏水 payload 可能分不开 |

- 双抗/多抗：确认分析方法是否识别所有臂；LBA 捕获/检测表位可能只测一个臂。

### 双抗/多抗

1. 先定分析物：完整双抗、总抗体（含半分子/错配）、bound、unbound；不同问题不同 assay。
2. 至少测完整/活性形式；用两个靶点或两个 anti-ID 表位，确保两臂都被识别。
3. 错配/半分子/游离臂会干扰总抗体；需要臂特异性 assay 或 LC-MS 特征肽。
4. target 干扰、hook、ADA 和试剂交叉反应必须单独验证。
5. 双抗的 ADA 可能针对不同臂/连接区；需要多域策略。

- 融合蛋白：区分融合伙伴、连接区、活性片段；LC-MS 特征肽要选独特肽。
- 纳米抗体/片段：肾清除快，基质/稳定性不同；LBA 试剂可能交叉。
- ADC 的 linker-payload：源内碎裂会污染游离 payload 通道；独立 MRM + 色谱分离。

## 6. 寡核苷酸 / LNP-RNA 等复杂递送体系

- 先分：完整 AOC、总抗体、偶联 oligo、游离 oligo；LNP 则是封装 mRNA/游离 mRNA/脂质组分/翻译蛋白。
- 杂交捕获 + LC-MS/MS 或 hELISA；RT-qPCR 不能区分封装/游离。
- LNP 需 ±Triton 做封装率；脂质 LC-MS 要分离与内标。
- 不能把 LNP-RNA 当成 siRNA/ASO 同类分析物；它是递送/修饰体系。

## 7. 特殊基质与特殊人群

| 场景 | 选择 | 关键控制 |
|---|---|---|
| 溶血 | LBA/LC-MS 均可 | 溶血基质单独验证；报告血红蛋白浓度 |
| 脂血 | LC-MS 优先；LBA 需验证 | 超滤/SPE；高脂个体 |
| 儿科/微量 | 微量 LC-MS 或 LBA | 低体积、低吸附、DBS/微采样 |
| 高蛋白/高盐 | LC-MS | 稀释/SPE；基质效应 |
| 组合用药 | 两法均可 | 药物-药物干扰、共享代谢/清除 |
| ADA 阳性 | LBA 可能被干扰 | 酸解离/抗独特型抗体；LC-MS 总药 |

## 8. 临床前 vs 临床

| 项目 | 临床前 | 临床 |
|---|---|---|
| 基质/种属 | 动物血浆、组织；多物种 | 人血浆/血清；固定抗凝剂 |
| 试剂 | 通用 anti-Fc/anti-ID；可用 target 捕获 | anti-ID/靶点捕获；需临床级试剂 |
| 验证 | 探索性可 fit-for-purpose；GLP 全项 | 注册研究按 M10 全项 + ISR |
| 范围 | 高浓度、稀释多 | 个体差异、target/ADA 干扰 |
| 桥接 | 种属/基质变更做部分验证 | 平台/site 变更做交叉验证 |

## 9. 平台选择的边界

- **LBA 测“结合/活性”，LC-MS 测“质量”**；两者不能直接互换。
- 复杂基质中 LBA 的“总浓度”可能只测可结合部分；LC-MS 的总浓度可能包含碎片/代谢物。
- 需要游离浓度时，分离步骤是方法的一部分；不能只在报告里写“free”。
- 组织匀浆的归一化方式（mg protein/g tissue）会改变结论；必须报告。
- 复杂体系的方法验证通常是 fit-for-purpose，不是所有情况都做 full M10。
