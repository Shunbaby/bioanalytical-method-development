# 接受标准与排障矩阵

## 1. 分析批接受

| 项目 | 最低要求 | 失败处理 |
|---|---|---|
| 校准曲线 | ≥6 非零；≥75% 且 ≥6 个在平台标准内（LC-MS ±15%，LLOQ ±20%；LBA ±20%，LLOQ/ULOQ ±25%） | 查标准/加权/模型/残留；不能只删点 |
| QC | ≥67% 在平台标准内（LC-MS ±15%，LLOQ ±20%；LBA ±20%）；每水平 ≥50% | 查加样/试剂/基质；重跑需预设规则 |
| 空白/零标 | < LLOQ | 查污染/残留/背景 |
| 残留 | ≤20% LLOQ | 洗针/空白针/管路 |
| 稀释 QC | LC-MS ±15%；LBA ±20% | 查稀释液/基质/hook |
| ISR | ≥67% 在 ±20% | 查稳定性/提取/校准；不要挑样 |

## 2. 验证项与失败路径

| 验证项 | 失败表现 | 首选排查 | 解决 |
|---|---|---|---|
| 准确度 | 同方向偏移 | 标准品/QC 配制、加样、试剂批 | 重配；换批；校准移液器 |
| 精密度 | CV 大 | 加样、孵育、提取、边缘孔 | 随机化；预热；优化提取 |
| 选择性 | 空白有峰/个体差异 | 内源物、基质、抗凝剂 | 换通道/色谱；个体基质；阻断 |
| 特异性 | 代谢物/同源物干扰 | 源内碎裂、交叉反应 | 分离；换表位；独立 MRM |
| 基质效应 | IS 归一化后仍 CV 大 | 磷脂/盐/蛋白；IS 不共洗脱 | SPE/PPT；SIL 内标；稀释 |
| 回收率 | 低或随浓度下降 | 提取、吸附、饱和 | 优化提取；加载体；换 SPE |
| 稀释线性 | 高浓度稀释后不准 | 稀释液、hook、基质 | 用空白基质；查 hook；改 MRD |
| 残留 | 空白 >20% LLOQ | 洗针、管路、进样量 | 洗针/空白针；改色谱 |
| 稳定性 | 时间/冻融下降 | 降解、吸附、酯酶 | 低温/避光/抑制剂；分装 |
| ISR | >33% 超 ±20% | 样品稳定性、提取、稀释 | 调查；不要只重跑 |
| Hook | 高浓度信号下降 | 饱和/一步法 | 稀释；竞争法/两步法 |
| 平行性 | 稀释不平行 | 基质/hook/抗体 | 提高 MRD；换稀释液 |

## 3. LBA vs LC-MS 的选择错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用 LBA 测游离 payload | 测的是结合/总 payload | 先分离，再 LC-MS |
| 用 LC-MS 测“活性” | 质量 ≠ 活性 | LBA/细胞法测活性 |
| 用总抗体代表 ADC | 暴露偏高、t½ 偏长 | 分总抗体/偶联抗体/游离 payload |
| 用平均 DAR 代表分布 | 隐藏 DAR0/高 DAR | 报 DLD；HIC/native MS |
| 用血浆方法测组织 | 提取/归一化错 | 组织匀浆 + 蛋白/重量归一化 |
| 用 ADA 方法套 M10 | 接受标准错 | 免疫原性专门指南 |

## 4. 复杂体系快速选择

| 体系 | 首选 | 备选 | 关键点 |
|---|---|---|---|
| 血浆大分子 | LBA | hybrid LC-MS | 抗体对、target/ADA |
| 血浆小分子 | LC-MS/MS | LBA（仅特殊） | IS、基质效应 |
| 组织 | LC-MS/MS | LBA | 匀浆/归一化 |
| 游离药物 | 分离 + LBA/LC-MS | — | 平衡/膜吸附 |
| 内源标志物 | LC-MS/MS | LBA | surrogate matrix |
| ADC 总抗体 | LBA | — | 含 DAR0 |
| ADC 偶联抗体 | LBA | — | DAR≥1 |
| ADC 游离 payload | 分离 + LC-MS/MS | — | ex vivo 释放 |
| DAR/DLD | HIC/native MS | LC-MS | 高疏水 payload |
| 寡核苷酸/AOC | 杂交 LC-MS/hELISA | PCR（仅 payload） | 分完整/总/游离 |

## 5. 方法转移/交叉验证

- 两平台/两 site：同批样品、同校准范围、同 QC；Bland-Altman/回归。
- 不能直接换算；分析物不同要说明。
- 接受标准预先定义；偏差记录。

## 6. 数据完整性

- 原始图谱/序列/积分参数可追溯。
- 审计追踪、权限、电子签名。
- 任何手动积分/重积分有理由和记录。
- 报告值与原始数据一致；不能只保留“最终结果”。
