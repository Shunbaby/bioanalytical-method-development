# LBA 方法开发

## 1. 格式选择

| 格式 | 适用 | 关键限制 |
|---|---|---|
| Sandwich | 大分子、多价抗原 | 捕获/检测表位不能冲突；需要两个抗体 |
| Competitive | 小分子、肽、单表位 | 标准品与样品竞争；曲线反向 |
| Bridging | 双价/多价分析物、ADA | ADA 方法另属免疫原性；不要套 PK 验证 |
| Direct/indirect | 研究级、筛选 | 基质干扰大；注册级慎用 |
| Cell-based | 功能/活性 | 细胞状态、批间差异；不是浓度方法 |

## 2. 关键试剂

- 捕获抗体、检测抗体：表位、种属、交叉反应、亲和力、批号。
- 抗原/标准品：纯度、盐型、分子量、活性、稳定剂。
- 偶联物：标记效率、批间差、游离标记物。
- 磁珠/板：吸附、封闭、孔间差。
- 关键试剂要有 COA、验收、储存、效期；换批做 bridging。

### 抗体配对检查

1. 表位是否冲突（竞争 ELISA/BLI/SPR）。
2. 是否识别目标种属和基质中的构象。
3. 是否被 target/ADA/可溶性受体干扰。
4. 是否识别 DAR0 或 payload 构象（ADC 专用）。

## 3. 标准品与校准曲线

- 标准品母液独立称量；记录盐型/水合/纯度。
- 校准曲线至少 6 个非零水平；覆盖 LLOQ–ULOQ。
- 4PL/5PL；加权 1/y²；比较回算偏差，不只看 R²。
- Anchor points 只帮助拟合，不能当定量点。
- 标准品与 QC 独立配制；不要用同一母液“自证”。

## 4. 基质与 MRD

- 空白基质：目标种属、目标抗凝剂、个体混合。
- MRD：最低必需稀释；必须证明基质效应被消除。
- 个体基质：按 M10/项目要求；至少覆盖高/低响应个体。
- 溶血/脂血：单独验证；报告影响。
- 组织匀浆：蛋白/重量归一化；匀浆效率验证。

## 5. 验证矩阵

| 项目 | 设计 | 接受 |
|---|---|---|
| 准确度/精密度 | 至少 5 浓度，低/中/高 QC，至少 6 批 | ±20%（LLOQ/ULOQ ±25%）；QC ≥67% 在 ±20% |
| 选择性 | 个体基质、空白、溶血/脂血 | 空白 < LLOQ；80% 个体 ±20% |
| 特异性 | 同源蛋白、target、ADA、代谢物 | 无显著交叉/干扰 |
| 稀释线性 | 至少 3 个稀释倍数 | ±20% |
| Hook | 高浓度系列稀释 | 报告 hook 阈值；定量在 hook 以下 |
| 残留 | 高浓度后空白 | ≤20% LLOQ |
| 稳定性 | bench/冻融/长期/Stock | ±20%（LLOQ/ULOQ ±25%） |
| ISR | 真实样品 | ≥67% 在 ±20% |

## 6. 常见问题

### 低信号

- 抗体浓度/标记失效；抗原纯度；孵育时间/温度；洗板过度；缓冲液 pH/盐。
- 解决：新配试剂；棋盘滴定；换批号；降低洗涤强度；加载体蛋白。

### 高背景

- 封闭不足；检测抗体浓度高；非特异结合；洗板不足；板/磁珠吸附。
- 解决：优化封闭（BSA/酪蛋白/鱼皮明胶）；降低检测抗体；加去污剂；增加洗涤。

### Hook effect

- 高浓度信号下降；稀释后回升。
- 解决：报告阈值；样品稀释；改用竞争法/两步法；不要只报高浓度低值。

### Target/ADA 干扰

- 可溶性靶点遮蔽表位；ADA 与药物形成复合物。
- 解决：加抗靶点抗体/阻断剂；酸解离；稀释；换表位；LC-MS 正交。

### 批间差异

- 关键试剂换批；板/磁珠批号；标准品降解。
- 解决：bridging；固定批号；新批平行比较；COA/验收。

## 7. LBA 的边界

- LBA 测“可结合部分”，不等于总质量；游离/总/ADA 要分开。
- 不能测 DAR 分布；只能测总抗体/偶联抗体等。
- 不能替代 LC-MS 的代谢物/碎片/结构信息。
- ADA 方法不在 ICH M10 范围；用免疫原性指南。
