# ELISA/LBA 实操开发：从抗体对到板内稳健性

> 工作手册，不是法规原文。ELISA 的“原理简单”不等于“方法稳健”；板、抗体、缓冲液、洗板和样品基质都会改变结果。

## 1. 先定格式

| 格式 | 适用 | 关键限制 |
|---|---|---|
| Sandwich ELISA | 大分子、双表位、血浆蛋白 | 两个抗体表位不能冲突；target/药物可能遮蔽表位 |
| Competitive ELISA | 小分子、单表位、激素 | 标准品与样品竞争；灵敏度受抗体亲和力限制 |
| Direct/indirect | 研究级、筛选 | 基质干扰大；注册级通常不用间接法 |
| Bridging ELISA | 双抗、ADA、复合物 | 需要两个结合臂同时可及；不要用于总抗体 |
| 均相/无分离 | 小分子、POCT | 受基质/内源类似物干扰；定量范围常较窄 |

选择原则：**先问“测的是结合事件还是质量”，再问“有没有两个不冲突的表位”**。

## 2. 抗体对筛选

1. 捕获/检测表位不重叠；最好用竞争实验或表位分组确认。
2. 捕获抗体包被效率、检测抗体标记效率要分别测；不要只看终信号。
3. 抗体对在目标基质中筛选，不只在缓冲液里筛。
4. 检查种属交叉、靶点交叉、结构类似物交叉；内源靶点可能竞争。
5. 抗体批间差异是 LBA 最大的隐性变量；关键试剂要留样、做 bridging。

## 3. 板与缓冲液

- 板：高结合 96 孔板，批次固定；边缘孔易蒸发，必要时不用最外圈或加封板膜。
- 包被：pH 9.6 碳酸盐缓冲液，4°C 过夜或 37°C 2 h；包被浓度用棋盘滴定定。
- 封闭：BSA、明胶、酪蛋白、无蛋白封闭液；含生物素的封闭液要避开生物素-链霉亲和素系统。
- 洗液：PBS/ TBS + 0.05% Tween-20；洗不干净→背景高，洗过头→信号低。
- 稀释液：含 1% BSA/0.1% Tween 的 PBS；高盐/低 pH 可减少非特异，但可能破坏抗原抗体结合。
- 检测：HRP/AP 底物；避光、计时、统一终止；读板前擦底板。

## 4. 优化顺序（不要一上来做全因子）

1. 棋盘滴定：包被浓度 × 检测抗体浓度，找信号/背景比。
2. 封闭液与稀释液：先定背景，再定信号。
3. 孵育时间/温度：室温 1–2 h 或 4°C 过夜；固定后不要随意改。
4. MRD（最低必需稀释）：证明基质效应被消除，且 LLOQ 仍可达到。
5. 洗板次数/体积：定 3–5 次，每次 300 µL；洗板机通道要防交叉。
6. 板间/批间：至少 3 块板、2 天、2 个操作者。

完成标准：低/中/高 QC 的回收率、CV、背景都在预设范围内，且 MRD 有数据支持。

## 5. 校准曲线

- 4PL/5PL；加权 1/y² 常用；不要只看 R²。
- 至少 6 个非零点，覆盖 LLOQ/ULOQ 和决策点；anchor 不能当定量点。
- 回算偏差：校准点 ±20%（LLOQ/ULOQ ±25%）；至少 75% 且 ≥6 个通过。
- 稀释线性/平行性：高浓度样品稀释后回算，偏差在可接受范围。

## 6. 干扰与假象

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 空白/基质高背景 | 封闭不足、非特异结合、板/试剂 | 换封闭液、加去污剂、预吸附 |
| 高浓度信号下降（hook） | 捕获/检测抗体被饱和 | 稀释后复测，报告 hook 阈值 |
| 个体基质差异大 | 异嗜性抗体、HAMA、RF、补体 | 加阻断剂、稀释、换抗体对 |
| 生物素干扰 | 样品含高剂量生物素 | 避免生物素系统或加阻断 |
| 靶点干扰 | 可溶性靶点遮蔽表位 | 加抗靶点抗体、酸解离、稀释 |
| 药物干扰 | 药物-抗体复合物 | 酸解离/稀释/换试剂；不要用总抗体代替游离 |
| 边缘孔偏低/偏高 | 蒸发、温度不均 | 不用边缘孔、封板、预热板 |

## 7. 验证与批接受

- 准确度/精密度：至少 5 个浓度、至少 6 批；校准 ±20%，LLOQ/ULOQ ±25%，QC ±20%。
- 选择性：至少 6 个个体基质；溶血/脂血/高胆红素；抗凝剂。
- 稀释线性、hook、平行性、MRD。
- 稳定性：室温、冻融、长期、全血/血浆、自动进样器（如适用）。
- 批接受：校准 ≥75%、QC ≥67%、每水平 ≥50%；空白 < LLOQ；残留 ≤20% LLOQ。

## 8. 常见错误

1. 只优化信号，不看背景/基质效应。
2. 抗体对只在缓冲液筛，没在血浆里筛。
3. 封闭液含生物素，和链霉亲和素系统打架。
4. 洗板不统一，边缘孔蒸发。
5. 高浓度样品不稀释，hook 被误判为低值。
6. 用总抗体方法测游离药物。
7. 换抗体批/板批不做 bridging。
8. 只报 R²，不报回算偏差。
