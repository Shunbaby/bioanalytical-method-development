# 进阶样品前处理：从 PPT/LLE/SPE 到 SLE、SALLE、在线 SPE 与磷脂去除

> 工作手册，不是法规原文。方法参数以实测回收率、基质效应、选择性和稳健性为准。

## 1. 选择前处理的总原则

前处理不是“把蛋白去掉”，而是同时解决四件事：

1. **释放分析物**：从蛋白/组织/脂质体/细胞中释放，避免人为降解。
2. **去除干扰**：磷脂、盐、蛋白、脂质、代谢物、内源性类似物。
3. **富集**：达到 LLOQ，尤其是低浓度、低离子化效率的化合物。
4. **稳定**：控制 pH、温度、酶、吸附、光/氧化。

选择依据：`pKa/logD`、溶解度、蛋白结合、稳定性、基质类型、LLOQ、通量、成本、自动化程度。

## 2. 基础技术的关键参数

### 蛋白沉淀（PPT）

- 沉淀剂：乙腈、甲醇、丙酮、三氯乙酸、高氯酸；乙腈最常用。
- 比例：血浆:有机相约 1:2–1:4；比例不足蛋白去除不完全，过高稀释/灵敏度下降。
- pH：酸/碱敏感化合物要控 pH；有些化合物在低 pH 共沉淀。
- 磷脂：PPT 不能有效去除磷脂，常需后续 SPE/磷脂去除或梯度避开。
- 96 孔板：注意孔间交叉、密封、离心/过滤；内标加样要均一。

### 液液萃取（LLE）

- 按 `logD` 和 pKa 调 pH：酸性药在低 pH 保持中性，碱性药在高 pH 保持中性。
- 溶剂：乙酸乙酯、甲基叔丁基醚、二氯甲烷、己烷/异丙醇混合；按极性选。
- 反萃取/双萃取：提高选择性；注意乳化、界面、内标分配。
- 吹干/复溶：温度过高会降解；复溶液用初始流动相，避免溶剂效应。

### 固相萃取（SPE）

- 吸附剂：C18、C8、混合模式（反相/阳离子、反相/阴离子）、聚合物、离子交换。
- 步骤：活化 → 平衡 → 上样 → 洗杂 → 洗脱；每步体积/流速要固定。
- 突破（breakthrough）：上样浓度/体积过高会丢失；用加标滤液检查。
- 批间差：柱/板批次、孔径、载量；关键方法要做批间验证。

## 3. 进阶技术

### SLE（supported liquid extraction）

- 惰性载体吸附水相，有机相流过；相当于“自动化的 LLE”。
- 适合脂溶性/中性化合物；减少乳化；需优化上样体积、溶剂、pH。
- 与 LLE 相比：通量高、操作简单；但选择性/回收依赖载体和溶剂。

### SALLE（salting-out assisted LLE）

- 高盐（硫酸铵/氯化钠）促进相分离；适合水溶性/极性化合物。
- 盐种类/浓度、溶剂、pH 影响回收；盐可能污染 MS/柱。

### 在线 SPE / 柱切换

- 自动化、减少人工、提高通量；适合大批量临床/非临床样品。
- 关键：阀切换时间、清洗/洗脱溶剂、 carryover、柱寿命、方法转移。
- 验证要包括：在线系统空白、残留、批间一致性。

### 磷脂去除

- 磷脂是 ESI 抑制主因之一；监测 `m/z 184`（胆碱头基）或相关碎片。
- 方法：混合模式 SPE、氧化锆/钛酸盐、磷脂去除板、LLE、梯度避开。
- 不要只看“去除率”；要证明目标物回收和基质效应同时可接受。

### 其他

- 免疫捕获：高选择性，适合蛋白/ADC/低丰度；注意抗体脱落/非特异。
- 微萃取/固相微萃取、MIP、适配体、纳米材料：研究/特殊场景，方法稳健性和批间差要验证。
- 微采样/DBS：HCT、打孔、提取；见 `broader-analytes.md`。

## 4. 特殊基质

| 基质 | 关键点 |
|---|---|
| 组织/肿瘤 | 匀浆、蛋白/重量归一化、血污染、异质性 |
| 头发/指甲/皮肤/骨 | 清洗/去污染、孵育/消化、药物沉积差异 |
| PBMC/细胞 | 细胞计数/蛋白归一化、裂解效率、培养基残留 |
| CSF/滑液/汗/泪/房水 | 低体积、低蛋白、吸附、人工基质替代 |
| 脂质体 | 破坏脂质体释放、分离游离/封装、脂质干扰 |

## 5. 挑战分子的前处理

- **脂质**：SPE/LLE、磷脂去除、内标；注意脂质异构体。
- **肽/蛋白**：变性/还原/烷基化/酶解；免疫富集；SIL 肽。
- **寡核苷酸**：杂交捕获、IP-RPLC、去盐；避免核酸酶。
- **ADC**：先定总抗体/偶联抗体/游离 payload；前处理不得人为释放 payload。

## 6. 前处理验证清单

- 回收率：低/中/高，至少 3 个浓度；稳定、可重复；不要求 100%。
- 基质效应：6 个体基质、柱后灌注、IS 归一化；CV ≤15%。
- 残留：高浓度后空白 ≤20% LLOQ。
- 稳定性：前处理前/后、室温、冻融、自动进样器。
- 选择性：空白基质、溶血/脂血、抗凝剂、结构类似物。
- 重现性：不同操作者/天/批/板；96 孔边缘效应。

## 7. 常见错误

1. 只优化回收率，不看基质效应/选择性。
2. PPT 后直接进样，磷脂把离子化压低。
3. LLE 不看 pH/logD，回收率低且不稳定。
4. SPE 上样超载/穿透，低浓度丢失。
5. 96 孔板边缘孔蒸发/吸附，批内漂移。
6. 在线 SPE 不做 carryover/系统空白。
7. 前处理改变分析物（水解、氧化、释放），却当成回收率问题。
