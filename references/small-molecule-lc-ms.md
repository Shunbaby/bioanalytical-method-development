# 小分子 LC-MS/MS 方法开发：理化性质、色谱、质谱与前处理

> 工作手册，不是法规原文。申报前以 ICH M10、FDA/EMA/NMPA 现行指南和 site SOP 为准。

## 1. 先看理化性质，不要先看仪器

小分子方法开发的起点是：**pKa、logP/logD、溶解度、稳定性、极性/电荷、分子量、是否易与蛋白共价结合**。

| 性质 | 影响 | 方法开发动作 |
|---|---|---|
| pKa | 决定不同 pH 下的电荷/保留/离子化 | 流动相 pH 避开 pKa±1；碱性药常用低 pH，酸性药也常用低 pH；高 pH 柱需专用固定相 |
| logP（中性） | 疏水性/膜亲和/磷脂结合/残留 | 仅作起点；高 logP 易强保留、残留、磷脂干扰 |
| logD（工作 pH） | 实际保留/提取/蛋白结合/离子化 | 比 logP 更有用；按血浆 pH 7.4 和流动相 pH 分别看 |
| 溶解度 | 标准品/复溶/线性范围 | 先选溶剂；避免有机相过高导致沉淀 |
| 稳定性 | 水解/氧化/光/热/酯酶 | 控制 pH/温度/避光；必要时加稳定剂 |
| 亲核/反应性 | 与蛋白/巯基/醛共价结合 | 避免错误前处理；用低吸附/淬灭剂 |

**结论：需要考虑 logP，但不能只用 logP。** 对可电离化合物，`logD(pH)` 和 `pKa` 比 `logP` 更能解释保留、提取和基质效应。logP 不能替代蛋白结合/游离药物测定，也不能用来推算 fu 作为注册数据。

### 快速判断

- `logD(pH 7.4) < 0`：极性大，C18 可能不保留；考虑 HILIC、混合模式、离子对（注意 MS 污染）。
- `0–2`：C18 可用，但可能需要低有机起始/梯度。
- `2–4`：常规 C18/苯基，反相最舒服的区间。
- `>4`：强疏水，易残留/磷脂干扰；考虑苯基/F5、较高有机、柱温、强洗针。
- `>5`：先解决溶解度/残留/基质效应，不要直接上高浓度进样。

这些是**起点**，不是硬规则；最终看实测保留、峰形、回收和基质效应。

## 2. 色谱柱怎么选

| 固定相 | 适合 | 注意 |
|---|---|---|
| C18 | 常规反相、广谱 | 疏水太强/极性太强都可能不合适；注意硅醇残留 |
| C8 | 比 C18 保留弱、速度快 | 高疏水化合物可减少残留 |
| 苯基/苯己基 | 芳香环、极性差异、异构体 | π-π 作用可改变选择性；与 C18 正交 |
| F5（五氟苯基） | 高疏水、碱性、卤代、极性化合物 | 对碱性/极性有独特保留；注意批次差异 |
| HILIC | 强极性/离子型、logD<0 | 高有机相；平衡时间长；基质效应可不同 |
| 混合模式（C18/SCX/SAX） | 带电/两性化合物 | 缓冲液/pH 要固定；方法稳健性要验证 |
| 手性柱 | 对映异构体 | 不是常规 PK 首选；需正交/活性数据 |

### 选择顺序

1. 先按 `logD/pKa` 判断反相是否保留；不保留再考虑 HILIC/混合模式/离子对。
2. 先用通用 C18 做 scouting；再根据选择性换苯基/F5。
3. 异构体/代谢物共洗脱：换选择性（苯基/F5）比改梯度更有效。
4. 高疏水/残留：C8/苯基、较高的有机洗针、较小进样量、柱温优化。
5. 方法稳健性：柱批间、pH、流动相批次、柱温、流速都要纳入。

**柱参数**：UPLC 常用 1.7–2.1 µm，HPLC 3–5 µm；柱径越小灵敏度越高但通量/堵塞风险越大；柱温影响选择性和峰形，不要只当“加快”。

## 3. 流动相怎么选

### 有机相

- **乙腈**：黏度低、峰形好、ESI 背景低；最常用。
- **甲醇**：对某些疏水/质子性化合物选择性更好，但黏度高、背压大、酯化/背景风险。
- 异丙醇/THF：强洗脱/难溶样品，注意黏度、背景、残留。

### 水相/添加剂

| 添加剂 | 用途 | 注意 |
|---|---|---|
| 0.1% 甲酸 | 正离子、改善峰形 | 负离子可能抑制；pH~2.7 |
| 0.1% 乙酸 | 温和酸化 | 离子化弱于甲酸 |
| 2–10 mM 乙酸铵/甲酸铵 | 缓冲/改善峰形 | 挥发性；控制 pH；浓度过高抑制 ESI |
| 氨水/碳酸氢铵 | 高 pH 碱性化合物 | 需高 pH 稳定柱；pH 准确 |
| TFA 0.05–0.1% | 峰形/蛋白沉淀 | **强抑制 ESI**；尽量不用/低浓度 |
| 离子对试剂（HFBA/TBA） | 寡核苷酸/强极性 | 污染 MS、清洗困难；专用系统 |

**pH 是流动相的第一变量。** 碱性化合物在低 pH 质子化，峰形通常更好，但保留可能下降；酸性化合物在低 pH 抑制解离、保留增加。pH 接近 pKa 时，峰形/保留对微小 pH 变化最敏感，方法不稳。

### 梯度

- 起始有机相应低于“目标刚好保留”的比例；不要一开始就 50% 有机。
- 斜坡要覆盖目标 logD 区间；高疏水化合物用更陡的洗脱/高有机清洗。
- 每针后高有机洗针 + 空白针；磷脂在 C18 上强保留，需足够清洗。
- 平衡体积要足；HILIC 尤其需要长时间平衡。

## 4. 质谱平台怎么选/怎么调

### 离子源

| 源 | 适合 | 备注 |
|---|---|---|
| ESI | 极性/可电离、蛋白/肽、多数药物 | 最常用；正/负模式按 pKa/官能团 |
| APCI | 弱极性/中性、高 logP | 热不稳定化合物慎用 |
| APPI | 非极性/多环芳烃 | 需 dopant；灵敏度依化合物 |
| ICP-MS | 金属/元素 | 不是有机小分子定量常规 |

### QqQ MRM 优化

1. 先做母离子扫描/Q1，确认 `[M+H]+`、`[M−H]−`、加合物（Na/K/NH4）。
2. 做子离子扫描，选 2 个特异性产物离子；定量通道 + 确认通道。
3. 优化碰撞能、源温、去溶剂气、毛细管/锥孔电压；不要只优化一个参数。
4. 检查源内碎裂：高源温/高锥孔电压会把目标打碎，导致母离子/子离子错配。
5. 检查离子比：两个通道的峰面积比应在可接受范围；基质中异常提示干扰。
6. 驻留时间/扫描速度要兼顾峰宽和灵敏度；不要为了多通道牺牲峰形。

### HRMS

- 精确质量、分辨率、质量窗；适合代谢物/未知物/多组分。
- 定量仍要评估线性、基质效应、内标；高分辨不等于免验证。

## 5. 前处理与 logP 的关系

- **蛋白沉淀**：通用、快；高 logP 化合物可能共沉淀/回收低；上清含磷脂/盐。
- **液液萃取**：按 logD 选溶剂；高 logP 用低极性溶剂，低 logP 可能萃取不完全；注意乳化。
- **SPE**：反相适合中等 logP；强极性用混合模式/离子交换；高疏水注意洗脱/残留。
- **稀释**：高浓度样品先稀释，减少残留和源污染。

## 6. 基质效应

- 来源：磷脂、盐、蛋白、抗凝剂、溶血/脂血、代谢物。
- 评估：6 个个体基质、柱后灌注、提取后加标 vs 纯溶液；IS 归一化后 CV ≤15%。
- 磷脂监测：m/z 184（胆碱）、[M+H]+ 相关通道；保留时间/梯度要避开。
- 解决：SPE/LLE、改梯度、稀释、SIL 内标、降低进样量；不要只靠“基质匹配曲线”掩盖。

## 7. 残留

- 来源：进样针/loop、柱头、管路、隔垫、高浓度样品。
- 标准：高浓度后空白 ≤20% LLOQ。
- 解决：强洗针（有机/酸/碱组合）、空白针、降低进样量、换管路/柱、C8/苯基替代 C18。
- 高 logP/碱性化合物最容易残留；方法开发阶段就要做，不要等到验证。

## 8. 稳定性

- 血浆/全血：酯酶、水解、氧化、光/热；冰上、避光、快速处理。
- 前处理：pH/温度/酶；内酯/开环、N-氧化物、酰基葡萄糖醛酸苷。
- 自动进样器：室温/弱酸性/长时间；验证 autosampler 稳定性。
- Stock/工作液：溶剂、吸附、冻融；低吸附管。
- 稳定性失败先查 pH/温度/容器，不要先怀疑仪器。

## 9. 方法开发顺序（建议）

1. 收集理化性质（pKa/logP/logD/溶解度/稳定性）。
2. 选标准品溶剂/浓度；确认溶解/吸附。
3. 选前处理（PPT/LLE/SPE）；算回收。
4. 选柱/流动相（按 logD/pKa）；做 scouting。
5. 优化 MS（母/子离子、碰撞能、源温）。
6. 评估基质效应/残留/稳定性。
7. 定 LLOQ/ULOQ/校准模型/加权。
8. 按 M10 做验证；不要跳过 pre-validation。

## 10. 常见错误

1. 只看 logP，不看 pKa/logD 和流动相 pH。
2. 所有化合物都用同一条 C18 梯度。
3. 用 TFA 改善峰形，却牺牲 ESI 灵敏度。
4. 高疏水化合物不做残留，验证时才失败。
5. 只做 pooled matrix，不看个体/溶血/脂血。
6. 内标加得太晚/不共洗脱。
7. 把“基质匹配曲线”当成基质效应已解决。
8. 用 logP 推算蛋白结合/fu，作为注册数据。

## 11. 边界

- 本文件是小分子 LC-MS/MS 的开发框架，不替代具体化合物的方法学论文/site SOP。
- 方法参数（柱、pH、源温）最终要用实测选择性与稳健性数据支持。
- 脂质/寡核苷酸/大分子另有专文；不要把小分子 logP 规则直接套到 LNP/寡核苷酸。
