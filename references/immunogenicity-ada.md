# 免疫原性 / ADA：边界与要点

> ADA 不属于 ICH M10。用 FDA 2019《Immunogenicity Testing of Therapeutic Protein Products》及现行免疫原性指南；不要用 PK 方法替代。

## 1. 分层策略

1. **Screening**：高灵敏、低假阳性率（约 5%）；detect low/high affinity ADA。
2. **Confirmatory**：竞争/亲和确认，排除非特异。
3. **Titer**：滴度，反映 magnitude。
4. **Neutralization**：中和抗体（NAb），反映功能影响。

## 2. 关键参数

| 参数 | 要点 |
|---|---|
| Cut point | 个体基质、治疗前样本、5% false positive |
| Sensitivity | 常要求 ≤100 ng/mL（ screening/confirmatory）；高风险可更低 |
| Drug tolerance | 有药存在时仍能检出 ADA；按 Ctrough/预期药物浓度设计 |
| Specificity | 竞争抑制；排除非特异 |
| Precision | 批间/批内 |
| Stability | 样品/试剂 |

## 3. ADA 与 PK 的相互影响

- ADA 可能加快清除、改变暴露/有效性；
- 药物存在会掩盖 ADA（drug tolerance）；
- 不要用 PK 低浓度反推 ADA；
- ADC 的 ADA 可能针对抗体、linker-payload 或新表位；需多域评估。

## 4. 常见问题

**Q：ADA 方法能套 M10 吗？**
A：不能。M10 不覆盖免疫原性；用专门指南。

**Q：ADA 阳性就说明中和吗？**
A：不。需 NAb 方法。

**Q：ADC 的 ADA 和总抗体 LBA 会互相干扰吗？**
A：会。ADA/药物复合物可影响捕获/检测；需 drug tolerance 和选择性。

## 5. 边界

- 本文件不提供 cut point 统计/申报模板；需 site SOP 和统计计划。
- 不同产品 ADA 发生率不可直接比较。
