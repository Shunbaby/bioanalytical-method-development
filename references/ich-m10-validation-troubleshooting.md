# ICH M10 验证项：失败原因与处理

> 工作手册，不是法规原文。申报前以 ICH M10 现行文本、FDA/EMA/NMPA 要求和 site SOP 为准。LBA 与 LC-MS/MS 的接受标准大体一致，但基质、选择性、平行性和干扰来源不同。

## 0. 先分清“分析失败”与“样品失败”

| 现象 | 先查 | 不要做 |
|---|---|---|
| 整批 QC 偏高/偏低 | 校准曲线、试剂/缓冲液、加样、孵育温度 | 不要只重跑；先找系统性原因 |
| 单个样品异常 | 样品溶血/脂血、采集时间、冻融、稀释错误 | 不要用“重跑”掩盖样品问题 |
| LLOQ 附近不稳 | 灵敏度、S/N、吸附、酶解/提取损失 | 不要把 LLOQ 抬高后当通过 |
| 只有高浓度失败 | hook、饱和、源内碎裂、残留 | 不要只报低浓度 |
| 只有低浓度失败 | 背景、灵敏度、基质效应、污染 | 不要只用 pooled matrix 复测 |

## 1. 校准曲线（Calibration curve）

**常见失败**：低端弯曲、高端饱和、回算偏差、截距异常、R² 很好看但低端不准。

| 根因 | 排查 | 解决 |
|---|---|---|
| 标准品浓度/盐型/纯度错 | 核对分子量、盐型、水合、活性；独立称量 | 重新配制母液；用独立对照品交叉核对 |
| 加权不对 | 低浓度残差大、高端主导 | 用 1/y² 或 1/x²；比较回算偏差，不只看 R² |
| 曲线模型不对 | 4PL/5PL 残差呈系统弯曲 | 比较 4PL/5PL/线性；选残差随机、LLOQ 最准的模型 |
| 吸附 | 低浓度标准逐级下降 | 加载体蛋白/表面活性剂；用低吸附管；现配现用 |
| 配制误差 | 单点偏离、重复性差 | 独立配制；双人核对；按体积/重量记录 |
| 残留 | 高浓度后低浓度偏高 | 加洗针、空白针；残留 ≤20% LLOQ |
| 标准品不稳定 | 时间依赖性下降 | 冰上操作、避光、加稳定剂；做 Stock/工作液稳定性 |

**接受**：至少 6 个非零水平；≥75% 且至少 6 个标准在平台标准内（LC-MS ±15%，LLOQ ±20%；LBA ±20%，LLOQ/ULOQ ±25%）；LLOQ/ULOQ 不能同时被剔除。

## 2. 准确度与精密度（Accuracy & precision）

**常见失败**：批内 CV 大、批间偏移、低/高 QC 不准、重复性差。

| 根因 | 排查 | 解决 |
|---|---|---|
| 加样误差 | 小体积、黏稠、气泡 | 校准移液器；用正置换/低吸附吸头；称重法验证 |
| 提取回收率不稳 | 内标回收率波动 | 内标加样前加；优化提取；用 IS 归一化 |
| 孵育/温度不均 | 边缘孔效应、水浴/孵育器不均 | 随机化板布局；预热；记录温度 |
| 试剂批间差异 | 新批试剂后突然偏移 | 关键试剂 bridging；固定批号；做批间比较 |
| 标准品/QC 配制错 | 所有 QC 同方向偏 | 独立配制 QC；核对盐型/纯度；双人复核 |
| 基质效应 | 个体基质差异大 | 个体基质验证；稳定同位素内标；稀释/MRD |
| 酶解不完全 | 肽段响应低且变异大 | 优化酶比例/时间/变性；做消化完全性检查 |

**接受**：至少 5 个浓度；QC ≥67% 在平台标准内（LC-MS ±15%，LLOQ ±20%；LBA ±20%），每个水平至少 50%；批内/批间精密度按 M10。

## 3. 选择性（Selectivity）

**问题**：空白基质出现信号、个体基质抑制/增强、溶血/脂血干扰。

| 根因 | 排查 | 解决 |
|---|---|---|
| 内源性结构类似物 | 空白/零标有峰 | 换 MRM 通道、提高分离度、免疫富集 |
| 基质抑制 | 个体基质响应低 | 稳定同位素内标；稀释；换提取/色谱 |
| 溶血/脂血 | 溶血/脂血基质偏差 | 单独验证；超滤/SPE；报告影响 |
| 抗凝剂 | 不同管型结果不同 | 固定抗凝剂；比较 Li-heparin/EDTA/ citrate |
| LBA 交叉反应 | 结构类似物/靶点干扰 | 换表位/抗体；加阻断剂；做 target 干扰 |

**接受**：按 M10 规定数量的个体基质；至少 80% 个体在 ±20%（LLOQ ±25% 如适用）；空白低于 LLOQ。

## 4. 特异性（Specificity）

**问题**：代谢物、降解产物、同源蛋白、ADA/靶点复合物被误测。

- LC-MS：看代谢物/源内碎裂是否落在同一 MRM；用不同通道、色谱分离、空白基质加代谢物。
- LBA：看同源蛋白、可溶性受体、靶点、ADA 是否交叉；做阻断/竞争实验。
- ADC：总抗体方法会测 DAR0；偶联抗体方法要确认只测 DAR≥1；游离 payload 方法要确认没有 linker-payload 源内碎裂。

**解决**：换捕获/检测表位、加阻断剂、换 MRM、先分离、用正交方法确认。

## 5. 基质效应（Matrix effect）

**问题**：个体基质中响应抑制/增强，IS 归一化后仍不稳。

| 根因 | 排查 | 解决 |
|---|---|---|
| 磷脂/盐/蛋白 | 柱后灌注看到抑制区 | SPE/PPT 净化；改梯度；延迟洗脱 |
| 内标不合适 | IS 与目标不共洗脱 | SIL 内标；类似物要验证共洗脱 |
| 提取回收率差异 | 个体回收率不同 | 优化提取；加 IS；做回收率实验 |
| 高脂/溶血 | 响应异常 | 单独基质验证；超滤/稀释 |

**接受**：个体基质 IS 归一化响应 CV ≤15%；至少 80% 个体在 ±20%（按 M10/项目）。

## 6. 回收率（Recovery）

- 不要求 100%，要求**稳定、可重复、不随浓度/个体剧烈变化**。
- 低/中/高三个浓度，比较提取后加标 vs 空白提取后加标。
- 回收率低但稳定可接受；回收率随浓度下降通常是吸附/饱和/提取问题。

## 7. 稀释线性（Dilution linearity）

**问题**：高浓度样品稀释后不准；hook 被误当线性。

- 用空白基质做稀释，不用水/缓冲液（除非证明等效）。
- 至少 3 个稀释倍数；稀释 QC 准确度/精密度：LC-MS ±15%，LBA ±20%。
- LBA：高浓度先查 hook；稀释后信号应回升。
- LC-MS：稀释后基质效应可能改变；用 IS 归一化并做个体基质。

## 8. 残留（Carryover）

- 高浓度后立即进空白；空白响应 ≤20% LLOQ。
- 解决：洗针、增加空白针、改针座/管路、降低进样量、换色谱条件。
- LBA：洗板不充分、孔间污染；增加洗涤、改变板布局。

## 9. 稳定性（Stability）

必须覆盖：

| 类型 | 设计 | 常见失败 | 解决 |
|---|---|---|---|
| 室温/ bench | 0/2/4/6/24 h | 降解、吸附 | 冰上、避光、加稳定剂 |
| 冻融 | 至少 3 次 | 反复冻融沉淀 | 分装；避免反复；记录次数 |
| 长期 | -20/-80 °C, 1/3/6 月 | 缓慢降解 | 监控；到期待测；不要外推 |
| Stock/工作液 | 按配制 | 溶剂挥发/吸附 | 现配；称重；低吸附管 |
| 全血/血浆 | 采集后放置 | 细胞摄取/酶解 | 冰浴、快速离心、加抑制剂 |
| 游离 payload | ex vivo 释放 | 酯酶/水解 | 抑制剂、低温、快速处理 |

**接受**：稳定性样品准确度/精密度在平台标准内（LC-MS ±15%，LLOQ ±20%；LBA ±20%，LLOQ/ULOQ ±25%）；与基线比无系统下降。

## 10.  incurred sample reanalysis（ISR）

- 目的：证明方法在真实样品中可重现，不是只对 QC 好。
- **ISR 属于 study sample analysis，不是 validation batch**；在样品分析阶段按 M10 计划执行。
- 选择：靠近 Cmax、消除相、异常/稀释样品；样本量按 M10 的样本量要求，覆盖整个研究浓度范围。
- 每个选中样品重复分析一次；接受：至少 67% 样品两次结果差 ≤20%（`|R1-R2|/mean ×100%`）。
- 失败处理：查样品稳定性、提取、校准、稀释、个体基质；不要只挑“好看”的样品重跑。

## 11. 平行性（Parallelism）/ 线性

- 用于 LBA 的高浓度样品稀释：不同稀释倍数结果应平行。
- 失败：hook、基质效应、抗体干扰；解决：提高 MRD、换稀释液、加阻断剂。
- LC-MS 的平行性更多是稀释线性 + 个体基质；不要和 LBA 的 parallelism 混写。

## 12. Hook effect（LBA）

- 症状：浓度越高信号越低；稀释后信号回升。
- 解决：报告 hook 阈值；样品稀释到 hook 以下；改用竞争法/两步法；不要只报高浓度“低值”。

## 13. 关键试剂批更换（Reagent lot change）

- 抗体、抗原、酶、磁珠、标准品换批：做 bridging，至少低/中/高 QC + 个体基质。
- 失败：偏移、灵敏度下降、背景升高；解决：重新优化浓度、换批号、做平行比较。
- 关键试剂要有 COA、验收、储存和效期记录。

## 14. 部分验证与交叉验证

| 变更 | 需要做什么 |
|---|---|
| 新基质（血浆→组织） | 部分验证：选择性、提取、稀释、稳定性 |
| 新种属 | 部分验证：个体基质、交叉反应、回收率 |
| 新范围 | 校准曲线 + LLOQ/ULOQ + 稀释线性 |
| 新平台（LBA→LC-MS） | 交叉验证：同一批样品两法比较，Bland-Altman/回归；不能直接换算 |
| 新试剂批 | bridging，不一定全验证 |
| 新分析 site | 方法转移/交叉验证 |

## 15. 分析批接受（Run acceptance）

- 校准曲线合格；QC 合格；空白/零标合格；残留合格；偏差记录完整。
- 失败批：先判定失败原因，再决定重跑；不能“删点/挑点”直到通过。
- 重跑规则：预先写进 SOP；样品重跑要有原始值、重跑原因、最终值选择规则。

## 16. 快速排障索引

| 症状 | 先查 | 常见解决 |
|---|---|---|
| 低信号 | 标准品、试剂、孵育、提取 | 新配标准；换试剂批；优化孵育/提取 |
| 高背景 | 封闭、洗板、抗体浓度、基质 | 优化封闭；增加洗涤；降低检测抗体 |
| 低浓度不准 | 吸附、曲线模型、LLOQ | 加载体；换加权；提高 LLOQ |
| 高浓度不准 | hook、饱和、残留 | 稀释；改格式；加洗针 |
| 个体差异大 | 基质效应、target/ADA | 个体基质验证；阻断；IS 归一化 |
| 残留高 | 洗针、管路、进样量 | 洗针/空白针；改色谱 |
| ISR 失败 | 稳定性、提取、稀释 | 查样品/提取/校准；不要挑样 |

## 17. 证据与边界

- M10 是 PK 生物分析指南；**不覆盖免疫原性/ADA、生物标志物**（后者按 fit-for-purpose/专门指南）。
- LBA 与 LC-MS 的接受标准不能机械互套；分析物不同。
- 复杂基质/组织/游离药物需要额外验证，不能只做血浆方法后“直接套”。
