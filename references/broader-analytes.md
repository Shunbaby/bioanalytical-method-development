# 扩展分析物：DBS、组织、游离药物、双抗、基因/细胞治疗

> 工作手册，不是法规原文。申报前以 ICH M10、FDA/EMA/NMPA 现行指南和 site SOP 为准。

## 1. DBS / 微量采血

- **先定分析物**：总药物、游离药物、代谢物、大分子/ADC；DBS 不是“把血浆方法搬到卡上”。
- **HCT 效应**：红细胞比容改变扩散、打孔体积、回收和基质；至少覆盖低/正常/高 HCT，报告 HCT 范围。
- **打孔/体积**：经典 DBS 打孔有 volcano effect；优先固定打孔位置/体积式微采样（VAMS/Mitra）。
- **提取**：含去污剂/高盐缓冲液；验证回收与浓度/HCT 无关；LBA 注意卡纸化学（FTA 变性剂可能破坏表位）。
- **校准/QC**：在空白全血中制备，走“点卡-干燥-打孔-提取”全流程；不能用血浆标准品加换算系数。
- **桥接**：DBS 与血浆用同批样品、HCT/全血-血浆分配；回归；不能直接互换。
- **大分子/ADC**：总抗体可行；游离 payload 不建议作为唯一指标（红细胞分配、酯酶、干斑继续释放）；DAR 不适用。

## 2. 组织 / 非液体基质

- **匀浆**：冰冷、加蛋白酶/酯酶抑制剂、固定 w/v；验证匀浆均匀性（多点 CV）。
- **归一化**：按 g 组织或 mg 蛋白；两者不可混用；血液本身带蛋白，蛋白归一化会被血污染放大。
- **血污染**：灌注/放血方式全研究统一；血红蛋白法需同种组织空白扣除；肝/肾/脾/心肌背景高。
- **稳定性**：不能在完整组织加标；匀浆前/后分开；冻融、匀浆温度、水解。
- **稀释线性**：用空白组织匀浆，不用水/缓冲液；至少 3 个倍数。

## 3. 游离药物 / 蛋白结合

- **定义 free**：未结合蛋白（超滤/平衡透析）≠ 未共价偶联（ADC free payload）；报告必须写清。
- **平衡透析 vs 超滤**：高结合/疏水优先平衡透析；超滤快但有非特异吸附/体积偏移。
- **fu 验证**：已知 fu 对照、回收、非特异吸附、稀释效应；不能只做一次。
- **ADC**：只有游离 payload 的 fu 有意义；总 payload 不能换算；抗体端 PPB 不能代替 payload。
- **组织暴露**：靶组织游离浓度比血浆总浓度更接近效应；但组织 fu 测定更难。

## 4. 双抗 / 多抗

- **分析物**：完整分子、总抗体（含半分子/错配）、bound/unbound、各臂特异性；不能只报“药物浓度”。
- **两臂识别**：两个靶点或两个 anti-ID；捕获/检测各识别一臂；检查空间位阻/表位冲突。
- **错配/半分子**：臂特异性 LBA + 特征肽 LC-MS/CE-SDS/native MS；不能只用总抗体。
- **ADA**：可能针对不同臂/连接区；多域策略；drug tolerance 分臂报告。
- **平台**：LBA 测结合/完整；LC-MS 特征肽测质量/片段；两者互补，不能互校。

## 5. 基因 / 细胞治疗

- **AAV**：载体基因组 qPCR/ddPCR、转导/表达蛋白、抗载体/抗转基因免疫；组织生物分布要归一化、防污染。
- **细胞治疗**：流式（表型/绝对计数）、qPCR/ddPCR（VCN/转录本）、测序（克隆/整合）；区分供体/宿主。
- **qPCR 验证**：效率、LLOQ、特异性、抑制物、污染；不能只看 Ct。
- **流式验证**：抗体/设门/补偿/灵敏度/稳定性；活细胞/冻存样本分开。
- **边界**：放行（身份/纯度/活力/效力）≠ 体内 PK；脱靶分析属基因组/分子分析，不是 LBA/LC-MS。

## 6. 选择顺序

1. 分析物是完整分子、总量、游离还是核酸/细胞？
2. 基质是否改变分析物（HCT、匀浆、血污染、冻存）？
3. 分离步骤是不是方法的一部分（free、组织、DBS）？
4. 平台读出是结合、质量还是序列/表型？
5. 变更（基质/种属/平台/试剂）是否需要部分验证/交叉验证？
