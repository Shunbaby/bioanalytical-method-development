# Hybrid LBA-LC-MS

> 适用：大分子/蛋白/抗体/ADC，LBA 不够特异或试剂不足，而 LC-MS 直接测又不够灵敏。

## 1. 三种 workflow

| Workflow | 做法 | 适用 | 限制 |
|---|---|---|---|
| 直接消化 | 沉淀/ pellet digestion + 酶解 + 特征肽 MRM | 高浓度、非临床 TK | 灵敏度较低；基质干扰 |
| 免疫富集 + 消化 | 抗体/靶点/anti-ID 捕获，洗脱，酶解，特征肽 MRM | 低丰度、临床 PK | 捕获效率、试剂、通量 |
| 完整蛋白 | 免疫富集 + LC-MS 完整质量 | 需要完整分子/亚型 | 灵敏度、加合物、去卷积 |

## 2. 什么时候选 hybrid

- 没有可靠的捕获/检测抗体对，但有一个可用的捕获试剂；
- LBA 受 target/ADA/可溶性受体干扰，需要质量特异性；
- 需要区分完整/片段/修饰/亚型；
- ADC：需要同时看总抗体、偶联 payload、游离 payload；
- 临床前 TK：可用通用 anti-human Fc 捕获，减少 anti-ID 周期。

## 3. 方法开发

### 捕获

- 抗 Fc、抗 CDR、anti-ID、target、抗 payload；选择取决于分析物。
- 捕获只富集“可结合”部分；不要以为捕获了总蛋白。
- 检查捕获效率、洗脱回收、非特异结合、target 干扰。

### 酶解

1. 变性（尿素/Rapigest/SDC）。
2. 还原（TCEP/DTT）。
3. 烷基化（IAA，避光，淬灭）。
4. 胰酶/其他酶；pH、温度、时间、酶比例固定。
5. 加 SIL 肽内标；检查漏切/完全性。

### 特征肽

- 选择独特、稳定、易离子化的肽；避免修饰/糖基化位点。
- 至少 1 个定量肽 + 1 个确认肽；每个肽至少 2 个 MRM。
- SIL 肽要尽早加，且与目标共洗脱。

### 色谱/质谱

- 反相 C18；甲酸/乙酸铵；避开磷脂/盐。
- ESI 正离子；MRM；检查源内碎裂、加合物、残留。

## 4. 验证

ICH M10 没有专门针对 hybrid 的章节；行业通常组合 LC-MS 与 LBA 原则：

| 项目 | 做法 |
|---|---|
| 校准/QC | LC-MS 曲线；至少 6 个非零水平 |
| 准确度/精密度 | 3 批（LC-MS 风格）或 6 批（LBA 风格），预先定义 |
| 选择性 | 6 个体基质（LC-MS 风格）；若捕获步骤主导，讨论是否需 10 |
| 基质效应/回收 | 捕获 + 消化 + LC-MS 全流程 |
| 稀释/残留/稳定性 | 按 LC-MS + 捕获步骤 |
| ISR | 真实样品；67% 在 ±20% |
| 关键试剂 | 捕获抗体/酶/磁珠批间 bridging |

> 行业常引用 20/25 接受标准（±20%，LLOQ ±25%）用于 hybrid；申报前需与监管/项目预先定义，不能把 LC-MS 的 15% 直接套到所有 hybrid。

## 5. 常见问题

### 捕获效率低

- 抗体亲和力/密度不足；洗脱太强；target 竞争；磁珠饱和。
- 解决：提高捕获量、优化洗脱、换 anti-ID、加解离步骤。

### 酶解不完全

- 变性/还原不足；酶比例低；抑制剂；时间短。
- 解决：优化变性/还原；增加酶/时间；去除抑制剂；用不同酶。

### SIL 肽不共洗脱

- 序列/修饰差异；柱残留；内标加入太晚。
- 解决：换 SIL 肽；优化梯度；尽早加内标。

### 临床 transfer 失败

- 非临床通用 anti-Fc 捕获不适用于临床；灵敏度不足；基质不同。
- 解决：开发 anti-ID/靶点捕获；交叉验证；不要直接桥接。

## 6. 边界

- Hybrid 不是“更高级的 LBA”；捕获步骤仍决定选择性。
- 不能测“总”蛋白，除非先解离复合物。
- 不能替代 DAR 分布；DAR 需 HIC/native MS。
