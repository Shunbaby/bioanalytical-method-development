# 区域法规差异：FDA / EMA / NMPA / PMDA

> 工作手册，不是法规原文。ICH M10 是基线，但申报路径、实施日期、局部要求和报告格式仍按地区。

## 1. 全球基线

- **ICH M10**（2022-05-24 Step 4）：生物分析方法验证与 Study Sample Analysis。
- **ICH M10 Q&As**（2022-11-16 Step 4）：替代基质、储备液 5%、ISR、N-in-1 等。
- 地区监管机构采纳时间不同；以当地现行公告为准。

## 2. 地区对照

| 地区 | 现行基线 | 关键点 |
|---|---|---|
| **FDA（美国）** | ICH M10（2022-11）；2026 生物标志物指南 | 药物 PK 方法按 M10；生物标志物按 2026 指南 FFP；ADC/免疫原性另有专门指南 |
| **EMA（欧盟）** | ICH M10；EU GMP/GLP；临床试验法规 | M10 已实施；方法转移/检查按 EU GMP；Q&As 适用 |
| **NMPA（中国）** | ICH M10 与 Q&As/FAQs 均自 2023-07-29 适用（以生物样品分析原始记录时间点为准） | 公告分别于 2023-01-29、2023-07-04 发布；CDE 技术审评；GCP/GLP 和中文申报资料仍按当地要求 |
| **PMDA（日本）** | ICH M10；日本 GLP/GCP | 以 PMDA 现行通知为准；局部桥接/语言要求 |
| **Health Canada** | ICH M10 | 以 HC 现行指南为准；临床/非临床路径不同 |

## 3. FDA 的边界

- 药物 PK/TK：ICH M10（FDA 2022 采纳）；不要继续把 2018 BMV 当现行。
- 生物标志物：2026 *Bioanalytical Method Validation for Biomarkers*；按 COU 做 FFP。
- ADC：2024 *Clinical Pharmacology Considerations for ADCs*；assay panel 按需精简。
- 免疫原性：2019 免疫原性指南；ADA 不套 M10 的校准/QC 体系。
- 2026 生物标志物指南发布时明确撤回 2018 BMV；申报前核对 FDA 指南页面。

## 4. EMA 的边界

- M10 已实施；Q&As 适用。
- EU GMP Annex 11 / GLP 对计算机化系统、数据完整性、设施有额外要求。
- 方法转移/交叉验证要写进 protocol；多中心临床要统一 SOP。
- 生物标志物/ADC 按 EMA 对应指南和 CHMP 科学建议。

## 5. NMPA 的边界

- ICH M10 与 Q&As/FAQs 均自 2023-07-29 起适用；判断依据是生物样品分析的原始记录时间点。公告发布日期分别为 2023-01-29（M10）和 2023-07-04（Q&As/FAQs）。
- CDE 技术审评关注：方法验证、ISR、基质、稳定性、数据完整性、对照品/关键试剂。
- 中国 GCP/GLP、人类遗传资源、样品出境等按当地法规；生物分析实验室资质/检查要求另列。
- 申报语言/格式按 NMPA/CDE 当期要求；不要只交英文报告。

## 6. 区域差异的高频点

| 点 | 处理 |
|---|---|
| 指南版本 | 在方法/报告写“版本+日期”，不要只写“符合 M10” |
| 接受标准 | M10 统一，但局部指南可能加严/补充；预先查 |
| 基质/抗凝剂 | 人种/临床实践差异；方法验证覆盖实际抗凝剂 |
| 方法转移 | 跨 site/跨平台要交叉验证；不能假定等同 |
| 数据完整性 | FDA Part 11、EU Annex 11、NMPA 数据完整性要求 |
| 生物标志物 | 按 COU；不要直接套 PK 的 ISR/QC |
| 语言/报告 | 按地区申报格式；保留原始数据 |

## 7. 申报前检查

- [ ] 目标地区现行指南版本/日期已核对（不是二手摘要）。
- [ ] 方法验证报告写明 M10 + 局部要求 + 偏离理由。
- [ ] 关键试剂/对照品来源、批号、纯度、稳定性齐全。
- [ ] ISR、方法转移、交叉验证按需完成。
- [ ] 数据完整性/电子记录符合当地要求。
- [ ] 生物标志物/ADC/免疫原性用对应指南，不混用。
