# 数据完整性、Part 11、LIMS 与自动化

> 工作手册，不是法律意见。数据完整性不是“补记录”，而是从样品到报告的整个生命周期可重建。

## 1. 为什么生物分析特别容易出问题

- 一批样品有校准、QC、空白、稀释、重跑、积分、手动峰、试剂批、仪器状态。
- 原始数据在色谱工作站，报告在 LIMS/Excel，样品在 freezer；三处不一致就是检查重点。
- 自动化（96 孔、在线 SPE、液体处理）提高通量，也放大“错位、残留、 tip 复用、孔映射错误”。

## 2. ALCOA+

| 属性 | 要求 | 生物分析落点 |
|---|---|---|
| Attributable | 可追溯到人/系统 | 唯一账号；禁共享登录；操作者/审核者 |
| Legible | 可读 | 原始图谱、元数据、积分参数可读 |
| Contemporaneous | 当时记录 | 审计追踪时间戳；不能事后补 |
| Original | 原始或真实副本 | 保留电子原始数据，不只 PDF |
| Accurate | 准确 | 方法/系统验证；计算受控 |
| Complete | 完整 | 失败批、重跑、异常、剔除都保留 |
| Consistent | 一致 | 术语、单位、版本、时间一致 |
| Enduring | 持久 | 保留期内可读、可恢复 |
| Available | 可获取 | 检查/审计可及时调取 |

## 3. 21 CFR Part 11 / Annex 11

- 21 CFR Part 11：电子记录/电子签名、访问控制、审计追踪、系统验证、记录保留。
- EU GMP Annex 11：计算机化系统、供应商、验证、数据备份、审计追踪、变更控制。
- MHRA/WHO：数据完整性全生命周期；ALCOA+。
- Part 11 不是“买软件就合规”；要证明系统按预期使用、权限分离、审计追踪不可关闭、备份可恢复。

## 4. 色谱工作站（CDS）检查点

1. 唯一账号、角色分离（分析员/审核员/管理员）。
2. 审计追踪开启且用户不能关闭；管理员改配置也留痕。
3. 系统时间同步、时区固定；禁止手动改时间。
4. 原始数据不可覆盖；重积分生成新版本并记录原因。
5. 手动积分必须有理由、前后图、审核；不能“为了好看”手动积分。
6. 失败批/中止批保留；不能删除。
7. 电子签名与记录绑定；打印/PDF 不是原始数据替代。
8. 备份包含元数据/审计追踪，定期做恢复测试。

## 5. LIMS 与样品链

- 样品登录、条码、 aliquot、冻融次数、储存位置、销毁记录。
- 样品转移/接收温度记录；异常（断链、融化）要偏差。
- 稀释、重跑、重新进样要与原样品关联；不能生成“孤儿结果”。
- 报告值可追溯到批、校准、QC、原始图谱、积分版本。

## 6. 自动化

- 96 孔/液体处理：孔位映射、tip 复用、死体积、清洗程序、批间 carryover。
- 在线 SPE/柱切换：阀切换、系统空白、残留、柱寿命。
- 自动化积分：算法版本、参数、人工复核；不能“自动通过”。
- 机器人/调度软件也要验证；异常处理（缺板、堵针、气泡）要有人工复核。

## 7. 检查准备清单

- [ ] 任选一个报告值，能否在 10 分钟内追到原始图谱、积分版本、批记录、样品链？
- [ ] 审计追踪是否完整、可读、包含谁/何时/为什么？
- [ ] 是否有共享账号、通用账号、离职人员账号？
- [ ] 失败批、重跑、手动积分是否有记录和理由？
- [ ] 电子表格是否受控（版本、公式保护、审核）？
- [ ] 备份是否恢复测试过？
- [ ] 自动化方法/板图是否版本控制？

## 8. 常见发现

1. 共享登录/通用账号。
2. 审计追踪被关闭或管理员可改。
3. 手动积分无理由、无审核。
4. 删除失败批/只保留合格批。
5. 只存 PDF，不存原始电子数据。
6. Excel 计算不受控、版本混乱。
7. 样品冻融次数记录不全。
8. 自动化孔位错位导致“看起来正常”的错值。
