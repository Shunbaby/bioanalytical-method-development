# HRMS、代谢物鉴定与挑战分子

> 工作手册，不是法规原文。HRMS 的“高分辨”不等于“免验证”。

## 1. 什么时候用 HRMS 而不是 QqQ

| 目的 | 首选 | 说明 |
|---|---|---|
| 已知目标物定量 | QqQ MRM | 灵敏度/动态范围/稳健性通常最好 |
| 代谢物鉴定/未知物筛查 | HRMS（QTOF/Orbitrap） | 精确质量、同位素、MS/MS |
| 多组分/非靶向 | HRMS | 可回溯数据；但定量验证仍要做 |
| 同分异构体 | HRMS + 色谱/离子淌度 | 质量相同，必须靠分离 |
| 反应性代谢物 | HRMS + 捕获剂 | 谷胱甘肽/ NAC 加合 |
| 蛋白/多肽 | HRMS 完整质量/自上而下 | 质量大、电荷多；需去卷积 |

## 2. 代谢物鉴定流程

1. **样品**：空白基质、给药后样品、阳性对照；必要时加捕获剂。
2. **前处理**：蛋白沉淀/SPE；避免分析物降解；富集低丰度代谢物。
3. **LC**：长梯度/高分辨率柱；保留极性/异构体；必要时二维 LC。
4. **HRMS 采集**：全扫描 + DIA/DDA；正/负切换；MS/MS。
5. **数据处理**：质量亏损、同位素模式、提取离子色谱、背景扣除、代谢物预测软件。
6. **结构推断**：MS/MS 碎片、裂解路径、与母药比较；必要时合成标准品/ NMR 确认。
7. **定量**：若代谢物有活性/毒性，需单独方法；无标准品时用半定量/相对响应，并说明。

## 3. 反应性代谢物

- 用 GSH、NAC、氰化物、胺等捕获；软电离（低源温）减少假阳性。
- 区分真实加合物与源内反应/背景；用空白/对照/稳定同位素。
- 报告：加合物体内暴露、GSH 耗竭、共价结合；不能只凭体外 HRMS 推断临床毒性。

## 4. 挑战分子的稳定性/分析

### 酯类前药

- 血浆酯酶快速水解；冰上、加酯酶抑制剂、快速分离；区分前药/活性物。

### 酰基葡萄糖醛酸苷

- 易水解/重排；低 pH/低温；避免强碱；区分母药、酰基 glucuronide、重排物。
- 水解后测“总母药”时，必须证明水解完全且不产生假母药。

### N-氧化物

- 热不稳定/源内碎裂，可能还原成母药；低源温、低温前处理、独立 MRM。

### 反应性/光敏/易氧化

- 避光、惰性气体、抗氧化剂、低温；避免金属催化；稳定性覆盖全流程。

### 互变/手性

- 互变：控制 pH/温度/时间；确认是否达到平衡。
- 手性：手性柱/衍生化；验证对映体分离、回收、稳定性；不能用手性总和代替单一体。

## 5. 内源性化合物

- 空白基质含分析物：surrogate matrix、标准加入、背景扣除、SIL 类似物。
- 校准：替代基质/替代分析物；证明平行性。
- 基线：个体/年龄/性别/饮食；不能只用 pooled matrix。

## 6. HRMS 定量验证

- 质量精度：ppm 级；质量窗不能太宽。
- 分辨率：与干扰物分离；同位素模式。
- 线性/LLOQ/QC：与 QqQ 一样验证；HRMS 不能跳过。
- 内标：SIL 优先；共洗脱。
- 基质效应/残留/稳定性：同样适用。
- 数据：原始文件、提取参数、质量窗、积分、审计追踪。

## 7. 常见错误

1. 把 HRMS 当成“免验证”的万能定量平台。
2. 只报精确质量，不做 MS/MS/保留时间确认。
3. 代谢物无标准品却报绝对浓度。
4. 不控制源内碎裂，把 N-氧化物/加合物误判。
5. 酰基 glucuronide 水解条件过激，母药假高。
6. 手性方法不验证对映体转化。
7. 内源物用外源空白曲线，基线失真。
